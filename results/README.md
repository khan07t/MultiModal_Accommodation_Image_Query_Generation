# Results

Every number in the README and in the notebooks is computed from the files in
this directory. Nothing here is regenerated at read time, so the published
figures stay checkable against the raw data.

## detection_outputs/

Raw OWL-ViT output, one CSV per amenity per prompt set, written at a permissive
0.05 threshold.

```
image, label, score, x1, y1, x2, y2
```

One row per detected box. Inference ran once at 0.05 and the confidence sweep
filters these rows afterwards, which is why exploring ten thresholds costs no
GPU time.

## detection_metrics/

`summary_<amenity>.csv` scores the detections above against the COCO ground
truth at every threshold in the sweep, for every prompt set:

```
prompt, conf, precision, recall, f1, mean_iou, tp, fp, fn
```

This is the source for the headline table. Regenerate it with
`python scripts/build_results_table.py`.

`negatives_<amenity>.csv` scores the same detections against images that contain
no instance of the target amenity, giving false-positive rate and specificity per
threshold. An image counts as a false positive if any detection survives, so this
counts images rather than boxes.

## question_generation_outputs/

`merged_detections_<amenity>_with_questions_all_models.csv` holds the text-only
generation runs, one column per backend (`generated_question_flan_base`,
`generated_question_llama70b`, and so on) alongside the detection row and the
prompt that produced it.

`dets_<amenity>_<prompt>_gemini3_perspectives.csv` holds the vision-conditioned
run: three questions for each of three traveller perspectives, in columns named
`gemini_3_{single,couple,group}_q{1,2,3}`.

The contrast between those two files is Finding 3 in the README.

## analysis_summary/

Aggregate tables behind Finding 4: BERTScore across the three Gemini variants,
fallback rates per model and per amenity, semantic diversity per amenity, and
the profile distinctiveness scores.

## figures/

Per-amenity detection plots (`F1_vs_threshold_*`, `PR_*`, `neg_curve_*`,
`prompt_comparison_full`) and, under `generation/`, the three question-generation
figures. All are regenerated by `scripts/build_generation_figures.py` and by
`run_detection.py` unless `--no-plots` is passed.

## Provenance

These are the results of the original full-scale runs, not a re-execution. The
detection CSVs cover the complete test split (1,531 images); the 46-image sample
committed under `data/sample/` is for running the notebooks, and scoring against
it produces very different, much smaller-sample numbers.
