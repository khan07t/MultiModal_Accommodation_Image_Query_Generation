# Data

| Folder | Contents |
|---|---|
| `annotations/` | Roboflow test-split annotations (COCO format) for all five amenities. Images are not included; these files are used to score the saved detections. |
| `sample/<amenity>/` | 6 annotated photos per amenity, plus 2 negatives (no amenity) for bathtub, kettle, hairdryer and TV, with a COCO file for the sample |
| `user_study_images/` | The 15 photos shown to participants in the user study |
| `sample_manifest.csv` | Which file is a positive, a negative or a user-study photo |

All images are provided by **trivago N.V.** and remain its property.
